# VAPT Writeups

Hands-on Vulnerability Assessment & Penetration Testing writeups,
documenting reconnaissance, exploitation, and remediation across
authorized lab environments (Metasploitable2, Kali Linux, and other
intentionally vulnerable practice targets).

Each writeup follows a consistent methodology:

1. **Objective & Scope** — what is being tested and why
2. **Reconnaissance** — port/service enumeration (Nmap)
3. **Exploitation** — identifying and exploiting the vulnerability
4. **Proof of Access** — verified evidence of the achieved access level
5. **Recommendation** — remediation steps a real organization would take
